# 📡 Digital Signal & Citra Processing

# FATMA AZILIA SAFITRI

Repository ini berisi hasil eksperimen dari mata kuliah **Pengolahan Sinyal Digital (Digital Signal Processing)** menggunakan **Python** dan **Google Colab**. Eksperimen ini mencakup operasi dasar pada sinyal diskrit dan citra digital, pengujian sistem linear melalui sifat homogenitas dan additivitas, serta analisis penerapannya dalam studi kasus nyata

# 🛠️ Libraries Used

- NumPy
- Matplotlib
- scikit-image
- Pandas

## 🚀 How to Run

1. Buka notebook menggunakan Google Colab atau Jupyter Notebook
2. Install library yang diperlukan (jika belum tersedia):
   ```bash
   pip install numpy matplotlib scikit-image pandas
   ```
3. Jalankan seluruh cell secara berurutan (Run All)

## 📊 Experiment Summary

- Berhasil mengimplementasikan operasi dasar pada sinyal diskrit (penjumlahan, penggeseran, dan amplifikasi)
- Berhasil menerapkan operasi dasar pada citra digital menggunakan Python
- Menganalisis sistem linier
- Menganalisis penerapan operasi dasar sinyal dan citra pada kasus nyata, seperti *brightness enhancement* pada citra digital

## 📌 Conclusion

Praktikum ini berhasil mengimplementasikan konsep dasar Pengolahan Sinyal Digital, meliputi operasi pada sinyal diskrit, pengolahan citra digital, serta pengujian sistem linear. Hasil eksperimen menunjukkan bahwa setiap operasi memberikan pengaruh yang berbeda terhadap sinyal dan citra, serta membantu memahami penerapan konsep DSP dalam berbagai aplikasi nyata
